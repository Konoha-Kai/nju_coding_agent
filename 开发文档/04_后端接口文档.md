# 后端接口文档

## 1. 模型客户端接口

### `ModelClient.chat(messages, tools=None, tool_choice="auto")`

用途：调用 DeepSeek OpenAI 兼容 Chat Completions API。

输入：

```python
messages: list[dict]
tools: list[dict] | None
tool_choice: str | dict
```

输出：

```python
ModelReply(
    content: str | None,
    tool_calls: list[ToolCall],
    finish_reason: str,
    raw: dict,
)
```

配置来源：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 无 | DeepSeek API key |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | OpenAI 兼容接口地址 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 当前测试模型名 |

说明：DeepSeek 官方文档说明 Chat Completions 请求使用 `messages`，工具调用使用 `tools` 和 `tool_choice`，工具类型为 function。

## 2. Agent 主循环接口

### `Agent.run(task: str) -> AgentResult`

用途：执行一次用户编程任务。

流程：

```text
构造 system prompt
加入 user task
while 未终止:
  调用模型
  如果模型返回 tool_calls:
    校验工具名和参数
    执行本地工具
    将结果作为 tool message 写回上下文
  否则:
    记录最终回复并结束
```

输出：

```python
AgentResult(
    success: bool,
    final_message: str,
    steps: int,
    changed_files: list[str],
    executed_commands: list[str],
)
```

## 3. Sprint 2 正式工具调用接口

Sprint 2 已切换到 DeepSeek/OpenAI 兼容的 `tools` / `tool_calls` 模式。Agent 每轮请求都会传入 `ToolRegistry.to_openai_tools()` 生成的工具 schema。模型返回 `tool_calls` 后，Agent 解析 function name 和 JSON arguments，调用本地工具，再用 `role=tool` 的消息回填结果。

### Assistant Tool Call

```python
ToolCall(
    id="call_1",
    name="read_file",
    arguments='{"path":"README.md"}',
)
```

### Tool Message

```json
{
  "role": "tool",
  "tool_call_id": "call_1",
  "content": "ok=True\n..."
}
```

## 4. Sprint 1 轻量动作接口

Sprint 1 初版暂不使用正式工具系统，也不启用 DeepSeek function tool calls。模型需要直接返回一个 JSON object，由本地 `agent.actions.parse_action` 解析。

### Action JSON

```json
{
  "action": "read_file",
  "path": "relative/path.py",
  "max_chars": 12000
}
```

当前支持动作：

- `list_files`
- `read_file`
- `write_file`
- `run_command`
- `final`

该设计用于 Sprint 1 快速完成最小闭环。Sprint 2 已升级为正式 `ToolSpec`/`ToolResult` 工具系统；该轻量 action 协议目前仅作为向后兼容路径保留。路径安全和危险命令审批进入 Sprint 3。

## 5. 工具接口

### Tool Schema

```python
ToolSpec(
    name: str,
    description: str,
    parameters: dict,
    handler: Callable[[dict], ToolResult],
)
```

### Tool Result

```python
ToolResult(
    ok: bool,
    content: str,
    metadata: dict,
)
```

## 6. 文件工具

### `list_files`

参数：

```json
{
  "path": ".",
  "recursive": false
}
```

返回：workspace 内文件列表。

### `read_file`

参数：

```json
{
  "path": "relative/path.py",
  "max_chars": 16000
}
```

返回：文件内容；超长时截断并提示。

### `write_file`

参数：

```json
{
  "path": "relative/path.py",
  "content": "..."
}
```

返回：写入结果和字节数。

## 7. 命令工具

### `run_command`

参数：

```json
{
  "command": "pytest -q",
  "timeout_seconds": 30
}
```

返回：

```json
{
  "exit_code": 0,
  "stdout": "...",
  "stderr": "...",
  "timed_out": false
}
```

安全规则：
- 默认工作目录为 workspace。
- 命令有超时。
- 拦截明显危险命令。
- 拦截命令参数中的 `..` 路径穿越和 workspace 外绝对路径。
- 高风险命令需要用户确认。

## 8. 日志接口

日志格式：JSONL。

每行事件：

```json
{
  "time": "2026-08-31T12:00:00+08:00",
  "session_id": "demo-001",
  "event": "tool_result",
  "data": {}
}
```

事件类型：

- `user_task`
- `model_request`
- `model_reply`
- `tool_call`
- `tool_result`
- `agent_finish`
- `agent_error`
