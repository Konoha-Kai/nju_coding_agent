## 6. Agent Demo：递归 Fibonacci

这个 demo 使用隔离目录：

```text
C:\Users\23639\Desktop\deep_search\南软考核\test
```

启动交互式 Agent：

```powershell
C:\Users\23639\.conda\envs\nju\python.exe -s main.py --chat --workspace C:\Users\23639\Desktop\deep_search\南软考核\test --max-steps 10 --session-id fibonacci-video-demo --verbose --compress-context --context-max-messages 8 --context-keep-recent 4
```

进入后输入第一句：

```text
请在当前 workspace 写一个 fib_recursive.py 文件。要求：用递归函数 fib(n) 计算 Fibonacci，F0=0，F1=1；再写 sum_fibonacci(count) 计算前 count 项的和；脚本直接运行时打印前 10 项列表和前 10 项的和。写完后不要解释太多，只告诉我写了哪个文件。
```

等 Agent 回答后，输入第二句：

```text
现在运行 python fib_recursive.py，告诉我前 10 项 Fibonacci 的和是多少，并说明测试输出是否正确。
```

最后退出：

```text
exit
```

预期关键现象：

```text
[task] started
[step 1] model requested write_file
[step 1] tool write_file ok=True ...
Agent: ...
[task] started
[step 1] model requested run_command
[step 1] tool run_command ok=True ...
Agent: ...
```

预期最终结论：

```text
前 10 项 Fibonacci 的和是 88
```

口播：

```text
这里展示真实 Agent demo。我用 --chat 做你一句我一句的交互，用 --verbose 展示模型每一步调用了什么工具，用 --compress-context 展示长任务时的上下文压缩能力。workspace 指向 test 文件夹，所以 Agent 只能在这个测试目录里写文件和运行命令。它先写 fib_recursive.py，再运行 python fib_recursive.py，最后回答前 10 项 Fibonacci 的和是 88。
```
