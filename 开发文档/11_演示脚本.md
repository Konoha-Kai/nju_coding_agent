运行：

```powershell

$env:HTTP_PROXY=''
$env:HTTPS_PROXY=''
$env:ALL_PROXY=''
C:\Users\23639\.conda\envs\nju\python.exe -s main.py "Read demo_workspace/calculator.py, run python -m pytest demo_workspace/tests -v, and summarize the result. Do not modify files. Use Windows-compatible commands only." --workspace . --max-steps 8 --session-id sprint4-demo-root
```
